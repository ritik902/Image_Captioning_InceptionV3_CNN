# Image_Captioning_InceptionV3_CNN
This project builds an image captioning application that can generate textual descriptions (captions) for input images. It combines deep convolutional neural networks (CNNs) for image feature extraction with recurrent neural networks (RNNs), specifically LSTM, for natural language generation. The architecture enables the model to “see” the image (via CNN) and then “speak” about it (via LSTM / NLP).
